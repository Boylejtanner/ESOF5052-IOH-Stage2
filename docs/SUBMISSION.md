# Sharing the Project

The report source is [report/main.tex](../report/main.tex). Compile it separately for the PDF. The repository contains code, notebooks without saved outputs, documentation, and selected aggregate results.

## Publish with GitHub Desktop

1. Sign in to your GitHub account in GitHub Desktop.
2. Add the local `ESOF5052-IOH-Stage2` repository.
3. Review the changes, create a commit, and select **Publish repository** or **Push origin**.
4. Keep the repository private unless public release is intended and permitted.

A private link does not grant access by itself. Invite the required people through **Settings > Collaborators** and have them accept the invitation. A public repository is accessible to anyone, not only people who receive the link.

Never publish clinical data, patient identifiers, credentials, or unreviewed generated artifacts. This documentation update does not publish or push any files.
